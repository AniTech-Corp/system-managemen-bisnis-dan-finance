# Pesan Kerja

Layar utama untuk mengirim dan membaca pesan kerja tim dalam satu tempat.

## Sub-fitur: Kirim Pesan

Menulis pesan kerja singkat dan mengirimnya ke rekan tim.

## Sub-fitur: Lihat Percakapan

Membaca semua pesan masuk dan keluar sesuai urutan waktu.

## Sub-fitur: Cari Pesan

Mencari percakapan berdasarkan kata kunci atau nama pengirim.
