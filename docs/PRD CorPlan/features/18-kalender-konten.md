# Kalender Konten

Rencanakan konten promosi mingguan biar tidak bingung mau posting apa.

## Spesifikasi

### Tujuan
Membantu pengguna merencanakan konten promosi mingguan agar tidak bingung menentukan apa yang akan diposting.

### Selesai bila
- Pengguna dapat mengelola jadwal konten mingguan di kalender.
- Pengguna mendapat saran ide konten yang relevan dengan produk dan tren.
- Pengguna dapat menandai konten sebagai sudah terbit.

## Sub-fitur: Jadwal posting

Buat jadwal konten media sosial di kalender sesuai rencana promosi.

### Tujuan
Membuat jadwal konten media sosial di kalender sesuai rencana promosi.

### Selesai bila
- Pengguna dapat memilih tanggal, platform, dan mengisi detail konten.
- Jadwal tampil di kalender mingguan.
- Pengguna dapat mengubah atau menghapus jadwal.

## Sub-fitur: Ide konten

Dapat saran topik promosi yang cocok dengan produk dan tren pasar.

### Tujuan
Memberikan saran topik promosi yang cocok dengan produk dan tren pasar.

### Selesai bila
- Pengguna melihat daftar ide topik berdasarkan produk dan tren.
- Ide dapat dipilih untuk mengisi jadwal posting.
- Ide disusun dengan bahasa sederhana.

## Sub-fitur: Tandai terbit

Tandai konten yang sudah diposting agar tidak terlewat atau dobel.

### Tujuan
Menandai konten yang sudah diposting agar tidak terlewat atau dobel.

### Selesai bila
- Pengguna dapat menandai konten sebagai "sudah terbit".
- Konten yang sudah terbit tampak berbeda (misal label).
- Konten yang sudah terbit tidak muncul sebagai konten yang harus diposting lagi.

## Task

### 1. Bangun halaman utama Kalender Konten dengan data tiruan

### 2. Buat modal form tambah dan ubah jadwal konten

### 3. Buat panel ide konten dan alur pilih ke jadwal

### 4. Tampilkan label status terbit pada kartu konten

### 5. Buat skema Prisma dan migrasi tabel jadwal konten

### 6. Buat modul dan endpoint CRUD jadwal konten

### 7. Buat API saran ide konten dari produk dan tren

### 8. Buat endpoint tandai konten sudah terbit
